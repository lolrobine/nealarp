# Coding-agent resources and skills

The skills in this repository supplement the project guidance; they are not runtime dependencies. The root [`AGENTS.md`](../AGENTS.md), current source, tests, and deployment constraints remain authoritative. Only consult a skill that matches the task. Do not clone whole upstream repositories or run skill setup commands automatically.

The GitHub Copilot collection is intentionally excluded, as requested.

## Maintenance notes

1. Review upstream instructions, behavior, and license before refreshing any copied skill; keep the source commit and review date recorded here.
2. Preserve the project-specific commands: use `corepack pnpm`, the existing Playwright configuration, and the GitHub Pages static-export constraints.
3. Skills provide task-specific guidance; they do not replace acceptance criteria, tests, or CI. Do not broaden the lint-warning baseline or add a dependency just to satisfy a skill.
