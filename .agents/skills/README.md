# Project-local agent skills

Start with the repository root [`AGENTS.md`](../../AGENTS.md), then consult only the skill that matches the task. If a skill conflicts with the current code, tests, deployment target, or root instructions, follow the project source of truth.

The selected upstream skills are pinned and attributed in [`docs/agent-resources.md`](../../docs/agent-resources.md). These are guidance files, not application dependencies. Do not run setup instructions from upstream skills automatically or install tools just to satisfy them.
