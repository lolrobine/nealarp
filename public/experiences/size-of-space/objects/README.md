# Object pictures for Size of Space

**Every image in this folder is AI-generated. None of them is a photograph.**

They were produced from text prompts for this project to give the scale
comparison something concrete to look at. They are illustrations of what each
object looks like, not evidence of it:

- Surface features, cloud patterns, crater fields and structural details are
  plausible renderings, not survey data.
- Nothing here should be cited, reused as reference imagery, or treated as a
  record of any real observation.
- The sizes the game compares come from `../../../../app/(experiences)/size-of-space/data.ts`
  and are independent of these pictures.

The user interface states this on the page itself, next to the images, so a
player is never shown one of these believing it is a photograph.
